# Telegram Group Manager

A Telegram bot for group management and moderation automation.

## Requirements

- Runtime specified by the project
- Telegram bot token
- Appropriate group administrator permissions for moderation features

## Installation

```bash
git clone https://github.com/ryoaonetsuki/telegram-group-manager.git
cd telegram-group-manager
```

Install the dependencies listed by the project.

## Configuration

Set the bot token and other configuration values using environment variables or the supported configuration file.

Never commit credentials.

## Run

Start the project's configured entry point and add the bot to a test group first.

## Usage

Grant only the Telegram permissions required by the features you actually use. Test moderation rules before enabling them in a production group.

## Security

Keep the bot token private and review administrator permissions regularly.
